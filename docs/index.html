Quickstart

From zero to an answer

Get a key from Google AI Studio and keep it in the environment, not in your code.

  1. Installgo get the module. Go 1.26 or newer.
  2. Set the keyexport GEMINI_API_KEY=…, or pass WithAPIKey.
  3. Create the clientgogemini.New(opts...) checks the key and applies a 60 s timeout.
  4. CallGenerateContent(ctx, prompt), then resp.Text().
main.go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/Allan-Nava/go-gemini/gogemini"
)

func main() {
    client, err := gogemini.New(gogemini.WithModel("gemini-3.8-flash"))
    if err != nil {
        log.Fatal(err)
    }
    resp, err := client.GenerateContent(context.Background(), "Say hello")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(resp.Text())
}

API

Package gogemini

Everything you need for a single-turn call. Runnable examples are on pkg.go.dev; request semantics are in the Gemini API reference.

SymbolKindWhat it does
New(opts...)funcBuilds a client. Returns ErrMissingAPIKey when neither WithAPIKey nor GEMINI_API_KEY gives a key.
WithAPIKey · WithModeloptionKey and model. The default model is gemini-3.8-flash; a models/ prefix is accepted.
WithHTTPClient · WithTimeoutoptionBring your own *http.Client, or change the 60 s timeout of the default one.
WithBaseURLoptionAnother host: a proxy, or an httptest server in your tests.
GenerateContent(ctx, prompt)methodSends one user prompt to :generateContent and returns the *Response.
Generate(ctx, req)methodSame call with a full GenerateContentRequest, for callers that build the contents themselves.
Response.Text()methodText of the first candidate; empty when the prompt was blocked (see PromptFeedback).
*APIErrorerrorNon-2xx reply: HTTP code, Google status such as RESOURCE_EXHAUSTED, and the message. Match it with errors.As.

Auth

One key, in a header

The client sends your key in the x-goog-api-key header, never in the URL, so it stays out of access logs and error messages. WithAPIKey wins over GEMINI_API_KEY.

The Bard-era design copied the __Secure-1PSID session cookie out of the browser. That cookie opens the whole Google account and the web endpoint was never meant for automated use, so it is not supported.

Never commit a key. Keep it in the environment or a secret manager, and restrict it in Google AI Studio.
