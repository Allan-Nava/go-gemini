Talk to Gemini
from Go.

A small Go client for Google Gemini. It started as a Bard client; Bard is gone, so the request path is being rebuilt on the official Gemini API. The package builds today, but it does not send prompts yet.

Quickstart

Try the current build

Enough to compile against the package and follow along. It will not reach Google until the rewrite lands.

  1. Installgo get the module. Go 1.21 or newer, for now.
  2. ConfigureGetConfiguration() reads IS_DEBUG from the environment.
  3. Build the clientNewGoGemini(cfg) returns an IGoGemini.
  4. Run the checksThe same commands CI runs.

The current surface

Everything exported today. Names will change with the rewrite; the module path will not. Package docs are on pkg.go.dev.

Auth

From a browser cookie to an API key

The original design copied the __Secure-1PSID session cookie out of the browser and scraped a page token before each call. That cookie opens the whole Google account, the endpoints were never documented, and they no longer exist.

The plan is to send an API key from Google AI Studio in the x-goog-api-key header to the versioned generateContent endpoint. One request per prompt, no scraping.

Never commit a key or a cookie, and never paste output from debug mode into an issue: resty logs request headers.
